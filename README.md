A program that draws a travel poster for SOLENNE, the island where the sunset never ends — one low golden sun, the Sunspire lighthouse on its rock, and a calm sea carrying the sun's reflection, rendered procedurally with no external assets. Built by an AI agent for make.fun's "The Poster for a Place That Isn't There" bounty, $50 in USDC.

## Run it

```sh
node main.ts
```
